📋 Contexte et Problématique

🌍 Le Défi Énergétique

L'énergie solaire est une source cruciale pour la transition énergétique mondiale. Cependant, l'accumulation de poussière, de saleté et de débris sur les panneaux solaires réduit leur efficacité de manière significative.

⚡ Impact de la Saleté

Réduction d'efficacité: 15-25%
La poussière crée une barrière opaque qui bloque les rayons solaires. Sur une ferme solaire de 1MW, cela représente une perte de 150-250kW.

💰 Coûts du Nettoyage Manuel

Main-d'œuvre coûteuse
Le nettoyage manuel est dangereux, coûteux et inefficace. Un technicien peut coûter 50-100€/heure.

Notre Solution: Un robot autonome qui nettoie efficacement et sobrement les panneaux solaires, sans consommer plus d'énergie qu'il n'en économise.

Calculs de Dimensionnement

DONNÉES DU SYSTÈME:
- Masse robot: M = 5 kg
- Angle inclinaison panneau: θ = 30°
- Coefficient frottement: μ = 0.3
- Accélération souhaitée: a = 0.5 m/s²
- Rayon pignon moteur: r = 0.03 m

FORCES EN PRÉSENCE:
F_gravité = M·g·sin(θ) = 5 × 9.81 × sin(30°) = 24.5 N
F_frottement = μ·M·g·cos(θ) = 0.3 × 5 × 9.81 × cos(30°) = 12.75 N
F_inertie = M·a = 5 × 0.5 = 2.5 N
─────────────────────────────────────────────────────
F_totale = 24.5 + 12.75 + 2.5 = 39.75 N

COUPLE MOTEUR REQUIS (2 moteurs):
C = (F_totale × r) / 2 = (39.75 × 0.03) / 2 = 0.596 N·m

✅ RÉSULTAT: Moteurs DC 12V / 1.5 N·m
   (Marge de sécurité × 2.5)

Rendement Mécanique

Analyse des pertes:
  • Réducteur engrenages: η₁ = 0.85
  • Transmission courroie: η₂ = 0.90
  • Frottements chenilles: η₃ = 0.95
Rendement global: η_total = 0.85 × 0.90 × 0.95 = 72.7%

Code Arduino - Contrôle PID

#include <Wire.h>

// Définitions des pins
#define MOTOR1_EN 10
#define MOTOR1_IN1 8
#define MOTOR1_IN2 9
#define ENCODER_A 2

// Variables du système
float speedTarget = 0.0;      // Consigne
float speedActual = 0.0;      // Vitesse mesurée
volatile long encoderCount = 0;

// Paramètres PID
float Kp = 5.0, Ki = 0.5, Kd = 0.1;
float errorSum = 0, lastError = 0;

void setup() {
  Serial.begin(9600);
  pinMode(MOTOR1_EN, OUTPUT);
  pinMode(MOTOR1_IN1, OUTPUT);
  pinMode(MOTOR1_IN2, OUTPUT);
  pinMode(ENCODER_A, INPUT_PULLUP);
  
  attachInterrupt(digitalPinToInterrupt(ENCODER_A), countEncoder, RISING);
  Serial.println("🤖 Robot initialized!");
}

void loop() {
  updateSpeed();  // Mesurer vitesse
  
  float error = speedTarget - speedActual;
  errorSum += error;
  float derivative = error - lastError;
  
  // Calcul PID
  float pwmOutput = Kp * error + Ki * errorSum + Kd * derivative;
  lastError = error;
  
  // Limitation PWM
  pwmOutput = constrain(pwmOutput, -255, 255);
  
  // Application commande
  if (pwmOutput > 0) {
    digitalWrite(MOTOR1_IN1, HIGH);
    digitalWrite(MOTOR1_IN2, LOW);
  } else {
    digitalWrite(MOTOR1_IN1, LOW);
    digitalWrite(MOTOR1_IN2, HIGH);
  }
  analogWrite(MOTOR1_EN, abs(pwmOutput));
  
  // Affichage télémétrie
  if (millis() % 100 == 0) {
    Serial.print("Target: ");
    Serial.print(speedTarget);
    Serial.print(" | Actual: ");
    Serial.println(speedActual);
  }
  
  delay(10);
}

void countEncoder() {
  encoderCount++;
}
